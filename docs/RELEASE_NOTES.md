# Panenka 출시 노트

## 1.0.12 (빌드 17) — 2026-09-07

빌드 16(내부 테스트)에서 발견된 총 구단가치 오표시 수정분을 더한 빌드. 스토어 게시 노트는 아래 그대로 사용.

### 스토어 게시용 (플레이 콘솔 · 앱스토어 "새로운 기능")
- 일부 선수 사진이 나오지 않던 문제를 고쳤습니다.
- 스쿼드 화면의 축구장 배경을 새로 디자인했습니다.
- 강화 단계 표시를 웹과 같은 배지로 통일했습니다.
- 스쿼드 메이커: 카드를 길게 눌러 끌어다 놓으면 자리를 바꿀 수 있습니다. 옮길 자리의 오버롤을 미리 보여줍니다.
- 스쿼드 메이커: 발동하지 않은 팀컬러를 누르면 부족한 자리에 맞는 선수를 추천하고 바로 배치할 수 있습니다.
- 검색 탭 최근 경기 스쿼드에 선수별 오버롤·급여와 총 급여·총 구단가치를 표시합니다.
- 포메이션 표기를 넥슨 데이터센터와 같게 맞췄습니다.
- 스쿼드 총 구단가치가 일부 선수 시세만 합쳐지던 문제를 고쳤습니다.

### 상세 (내부 기록)
- 선수 사진: 넥슨 CDN에 카드별 액션 이미지가 없는 경우(예: 848 매디슨·852 쿨루셉스키) 서버 주소 → spid → pid 순으로 대체 주소를 시도하는 공용 위젯(FaceImage) 도입, 검색 탭 스쿼드는 서버가 준 주소 우선.
- 축구장 배경: 시안 A(가로 잔디 결·상단 광원·라인 마킹) 공용 위젯(PitchField) — 스쿼드 탭·검색 스쿼드·경기 상세.
- 강화 배지: 웹 대시보드 CSS 규격(정사각·숫자만·단계별 색·테두리·그림자, 11~13강 플래티넘 판 이미지 내장) — 배지 6곳 + 이적시장 글자 2곳.
- 스쿼드 탭: 총 급여·총 구단가치를 스쿼드 그림 위 좌우 2칸으로 이동(인원 표기 제거), 팀컬러 카드는 그림 아래로.
- 드래그 스왑: 길게 눌러 끌기(0.25초), GK 잠금, 선수 자리=교체·빈 자리=이동, "RCB 85 → CB 83" 미리보기 (넥슨 스쿼드메이커 규칙).
- 팀컬러 추천: 서버 tc-members API, 인물(pid) 기준 제외·대표 카드 1장·자리별 상위 3·손해 자리 접기, 슬롯 강화 유지 배치 (웹 B안 이식).
- 시세(빌드 17): 앱 캐시의 시세 만료 판정을 '메타 받은 시각'→'시세 받은 시각' 기준으로 수정(유저 스쿼드 흡수 뒤 재요청이 건너뛰어지던 결함), 총 구단가치 아래 '시세 미확보 N명 · 다시 시도'/'기준 HH:MM' 보조 줄, 서버는 재조회 실패 시 만료 시세를 price_at·price_stale과 함께 동봉.
- 포메이션: 표시 시점 0줄 생략(fmtFormation) — 랭커 드롭다운·랭커/유저 스쿼드 라벨·검색 탭 선발 스쿼드·이적시장 손익.
